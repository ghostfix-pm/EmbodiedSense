# MVP 1 范围与后续路线

按 2026-10-10《具身智能数据》对话的最后一轮执行任务实施：
优先交付可运行的 RGB-D 原型，不把整份长期规划同时塞进第一版。

## 已实施的 MVP 1

统一数据结构、TUM 索引和图像读取、精确时间戳、容差同步、质量报告、
米制彩色点云、显式坐标变换、CLI、Python API、自包含记录与回放、Rerun 记录。
合成样例用于数值测试；真实 TUM 数据用于实际流水线验收。

## 后续候选里程碑

1. AI 感知插件：接入现成目标检测器，将检测区域与有效深度关联，
   保留模型版本、检测得分和几何信息。确定模型后单独核对许可证及资源要求。
2. 空间状态：时间跟踪、坐标树、外部 SLAM 接口，明确估计值和观测值。
3. 模型增强实验：同一模型、同一传感器输入，比较直接输入、提示词、
   增加传感器以及完整处理四种方案，实测收益和时延，不预设提升数字。
4. ROS 2：核心外部的订阅/发布适配器，QoS 与有界缓存；在线同步器必须因果。
5. 边缘部署：先测瓶颈，再选择 ONNX、TensorRT、C++ 等；加入资源限制和故障恢复。

这些功能尚未实现，v0.1 不要求 GPU 推理、模型训练、机器人硬件或系统重装。
Rerun 查看器的图形渲染与 GPU 模型推理是两件事，`doctor` 只列出显卡资产，
不会把识别到 GPU 当作已验证 CUDA 推理。
